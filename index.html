Feedback Mood Checker

A School Project on AI (NLP)
Made by: Naseem. N, E. Niranchan, Pranish Bala, Prajeeth
Class XII-C1, Maharishi International Residential School

1. Aim

This computer program reads a school feedback comment and tells if it is Positive, Neutral or Negative. It helps the school see what students like and what needs to be improved.

3. Summary for Management

Write one comment on each line.

4. How accurate is it?

Rows = real answer, columns = computer answer. We used 300 made-up comments (100 each), so the accuracy is higher than it would be with real comments.

5. How it works

  1. Clean the text (small letters, no numbers or symbols).
  2. TF-IDF changes words into numbers.
  3. Logistic Regression picks Positive, Neutral or Negative.
  4. A teacher reads the Negative comments before any decision.
This is only a guide. It is never used to find or punish a student. SDG 4: Quality Education.
